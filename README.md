# Zyad Ai Pro - Transcription App 🎙️📝

تطبيق ويب متطور مدعوم بالذكاء الاصطناعي (Gemini AI) مصمم خصيصاً لاستخراج وتحويل الصوتيات والفيديوهات (خاصة الخطب والمقاطع الدينية) إلى نصوص مكتوبة بدقة عالية، مع دعم كامل للغتين الكردية (السورانية) والعربية.

## 🌟 المميزات

- **تحويل دقيق**: استخراج النص من الصوت والفيديو بأحجام تصل إلى 2 جيجابايت.
- **الحفاظ على المصطلحات الدينية**: يضمن كتابة الآيات والأحاديث والمصطلحات الدينية بالرسم العربي الصحيح 100%.
- **وضعيات متعددة**:
  - *شكل الكتاب (Book Mode)*: تنسيق النص ليكون جاهزاً للطباعة ككتاب ديني (إزالة التأتأة، تنظيم الفقرات، وضع الآيات بين أقواس ﴿ ﴾).
  - *النص الأصلي (Raw Mode)*: كتابة ما يُقال حرفياً كلمة بكلمة.
- **النسخ المباشر**: ميزة تحويل الصوت المباشر من الميكروفون إلى نص في الوقت الفعلي.

## 🚀 كيفية الرفع والتشغيل على GitHub Pages

هذا المشروع مجهز بالكامل ليعمل تلقائياً باستخدام **GitHub Actions** ليتم استضافته على **GitHub Pages**.

### الخطوة 1: ارفع الملفات إلى مستودعك
قم برفع جميع ملفات المشروع إلى مستودع (Repository) جديد في حسابك على جيت هب.

### الخطوة 2: إعداد الـ API KEY السري
لكي يعمل الذكاء الاصطناعي (Gemini)، يجب توفير الـ API Key الخاص بك دون فضحه في الكود المفتوح:
1. اذهب إلى صفحة مستودعك على GitHub.
2. اضغط على **Settings** (الإعدادات).
3. من القائمة الجانبية، اذهب إلى **Secrets and variables** ثم اختر **Actions**.
4. اضغط على الزر الأخضر **New repository secret**.
5. في خانة **Name** اكتب تماماً: `API_KEY`
6. في خانة **Secret** ضع المفتاح الخاص بك (مثل: `AIzaSyA...`).
7. اضغط **Add secret**.

### الخطوة 3: تفعيل GitHub Pages
1. اذهب إلى قسم **Settings** ثم **Pages**.
2. تحت قسم **Build and deployment**، تأكد من اختيار **GitHub Actions** من القائمة المنسدلة (Source).

سيقوم GitHub الآن تلقائياً ببناء مشروعك في كل مرة تقوم فيها بتحديث الملفات ورفعه على رابط موقعك.

## 🛠️ التطوير المحلي (Local Development)

إذا أردت تشغيل المشروع على حاسوبك للتطوير:

1. قم بتثبيت الاعتماديات:
   ```bash
   npm install
   ```
2. لتشغيل خادم التطوير:
   ```bash
   npm run dev
   ```
3. لبناء المشروع للنسخة النهائية:
   ```bash
   npm run build
   ```

*تم تطوير هذا الموقع لتسهيل نشر وتوثيق المحتوى الديني.*
